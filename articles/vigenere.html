Chiffre de Vigenère - clé mot clair

~ 7 min

Le chiffre de Vigenère est un système de chiffrement par substitution polyalphabétique1 symétrique. Il a été inventé par le diplomate français Blaise de Vigenère2 au XVIème siècle.

Ce chiffrement est utilisé pour protéger les communications sensibles en rendant l'analyse de fréquence plus difficile, aussi nommer "Le chiffre indéchiffrable". Il a finalement été "cassé" mathématiquement par Charles Babbage et Friedrich Kasiski au XIXe siècle, démontrant ainsi que même les systèmes de chiffrement les plus complexes peuvent être vulnérables à des attaques bien conçues. Depuis le chiffre de Vigenère n'offre plus aucune sécurité.

Comment fonctionne-t-il ?

Le chiffre de Vigenère utilise une clé de chiffrement constituée d'un mot ou d'une phrase. Chaque lettre du message clair est chiffrée en utilisant la lettre correspondante de la clé, selon un tableau de substitution polyalphabétique. Cela rend l'analyse de fréquence plus difficile, car chaque lettre peut être remplacée par plusieurs lettres différentes selon la position dans le texte et la clé utilisée.

> Exemple de chiffre de Vigenère :

Pour chiffrer le message "HELLO" avec la clé "WORLD", on utilise la table de Vigenère :

  1. Prendre la le mot clair "HELLO"
  2. Prendre la clé "WORLD"
  3. Utiliser la table de Vigenère pour chiffrer chaque lettre. En reliant avec l'intersection de la lettre du message clair à la lettre correspondante de la clé. Prenons la lettre "H" du message clair et la lettre "W" de la clé cela nous donne "D" car si nous descendons de H jusqu'à W dans la table, nous trouvons "D".
    • Si la clé est plus courte que le message, elle est répétée pour couvrir toute la longueur du message. (e.g., "WORLD" devient "WORLDW")
    • Si la clé est plus longue que le message, elle est tronquée pour correspondre à la longueur du message. (e.g., "WORLD" devient "WORL")
  4. Inversement, pour déchiffrer le message chiffré "DSCWR" avec la clé "WORLD", on utilise la table de Vigenère en reliant l'intersection de la lettre du message chiffré à la lettre correspondante de la clé.

Cela nous donne le message chiffré "DSCWR". Nous remarquons la substitution polyalphabétique de chaque lettre du message clair par une lettre différente selon la clé utilisée.

Voici le coeur du chiffre de Vigenère, la formule mathématique :

On remplace chaque lettre par sa position dans l'alphabet (A=0, B=1, ..., Z=25)

À vous de modifier la formule selon vos besoins. Chiffré / Déchiffré, petit piège si vous voulez isoler Message pensez au nombre négatif qui ne désigne pas une lettre valide.

Donc même sans tableau nous pouvons chiffrer et déchiffrer des messages avec le chiffre de Vigenère.

Application du chiffre de Vigenère (Java)


    
    public class Vigenere {
    
        public static String executer(String texte, String cle, boolean chiffrer) {
            if (cle == null || cle.isEmpty()) return texte;
    
            StringBuilder resultat = new StringBuilder();
            int decalageCle = 0; // Pour ignorer les espaces dans la progression de la clé
            int sens = chiffrer ? 1 : -1;
    
            for (int i = 0; i < texte.length(); i++) {
                char c = texte.charAt(i);
    
                if (Character.isLetter(c)) {
                    // On définit la base (A ou a) pour gérer la casse
                    char base = Character.isUpperCase(c) ? 'A' : 'a';
                    
                    // Récupération du caractère correspondant dans la clé
                    char charCle = cle.charAt(decalageCle % cle.length());
                    int valeurCle = Character.toUpperCase(charCle) - 'A';
    
                    // Application de la formule mathématique unique
                    // (c - base) extrait l'index 0-25
                    int index = (c - base + (sens * valeurCle) + 26) % 26;
                    
                    resultat.append((char) (base + index));
                    decalageCle++;
                } else {
                    // Si c'est un espace ou ponctuation, on l'ajoute tel quel
                    resultat.append(c);
                }
            }
            return resultat.toString();
        }
    
        public static void main(String[] args) {
            String msg = "HeLlO WoRlD!";
            String cle = "world";
    
            String code = executer(msg, cle, true);
            System.out.println("Chiffré : " + code);
    
            String decode = executer(code, cle, false);
            System.out.println("Déchiffré : " + decode);
        }
    }
Chiffré : DsCwR ScIwG!
Déchiffré : HeLlO WoRlD!

Vulnérabilités

Le chiffre de Vigenère, bien qu'étant plus sécurisé que les méthodes monoalphabétiques, présente plusieurs vulnérabilités :

  • Attaque par l'analyse de la longueur de la clé : Si la clé est courte et répétée, on peut utiliser des techniques comme l'analyse de l'indice de coïncidence pour déterminer sa longueur.
  • Attaque par force brute : Pour les clés courtes, il est possible d'essayer toutes les combinaisons possibles.
  • Attaque par analyse de fréquence : Une fois la longueur de la clé connue, on peut appliquer l'analyse de fréquence à chaque sous-texte.

Conclusion

Le chiffre de Vigenère a joué un rôle important dans l'histoire de la cryptographie, représentant une avancée significative par rapport aux méthodes de chiffrement monoalphabétiques. Bien qu'il ait été considéré comme inviolable pendant plusieurs siècles, son inefficacité face aux attaques modernes le rend aujourd'hui principalement intéressant pour les historiens et les passionnés de cryptographie.

1 Un chiffre de substitution polyalphabétique est un type de chiffre dans lequel chaque lettre du message clair est remplacée par une lettre différente, en fonction de sa position dans le texte et d'une clé. Contrairement aux chiffres de substitution monoalphabétiques, où chaque lettre du message clair est remplacée par la même lettre du message chiffré, les chiffres polyalphabétiques utilisent plusieurs alphabets de substitution pour rendre le chiffrement plus complexe et résistant aux attaques par analyse de fréquence.

2 Blaise de Vigenère (1523-1596) était un diplomate français, cryptographe et mathématicien. Il est surtout connu pour avoir inventé le chiffre de Vigenère, un système de chiffrement par substitution polyalphabétique qui a été largement utilisé pendant plusieurs siècles. Bien que le chiffre de Vigenère ait été considéré comme inviolable pendant longtemps, il a finalement été cassé au XIXème siècle grâce à l'analyse de fréquence et à d'autres techniques cryptographiques. Malgré cela, Blaise de Vigenère reste une figure importante dans l'histoire de la cryptographie.
